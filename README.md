# Smart Calculator

A responsive calculator built using HTML, CSS, and JavaScript.

## Features
- Addition
- Subtraction
- Multiplication
- Division
- Remainder calculation
- Input validation
- Division-by-zero protection
- Responsive layout

## Technologies Used
- HTML5
- CSS3
- JavaScript

## How to Run
1. Clone or download this repository.
2. Open `index.html` in your browser.
3. Enter two numbers, select an operation, and click Calculate.# smart-calculator
